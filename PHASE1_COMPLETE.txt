## Architecture Changes

OLD:
Upload → process_task() → Load all models → Transcribe + Summarize (forced)

NEW:  
Upload → Transcribe (optional diarization) → Summarize (optional) → Visualize (optional)

Each step:
- Separate Celery task
- Singleton model managers
- Lazy loading
- Async + Sync modes
- Status polling

- Model reuse: 24.6x faster

- Optional LLM: Save 30-60s if not needed
- Parallel ready: Multiple workers can process different steps
