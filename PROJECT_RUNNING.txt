Option 2: Test V2 API (Modular - Recommended)
  Via Postman/curl:
  
  Step 1: Upload
  POST http://localhost:8000/api/v1/audio/v2/upload
  Body: form-data
    - file: [your_audio.mp3]
    - case_id: 1
  Response: {"task_id": "...", "status": "uploaded"}
  
  Step 2: Transcribe
  POST http://localhost:8000/api/v1/audio/v2/transcribe/{task_id}
  Body: {
    "enable_diarization": true,
    "diarization_method": "pyannote",
    "language": "vi",
    "async_mode": true
  }
  Response: {"task_id": "...", "status": "processing"}
  
  Step 3: Poll Status
  GET http://localhost:8000/api/v1/audio/v2/tasks/{task_id}/status
  Response: {"status": "transcribed", "transcript": "..."}
  
  Step 4: Summarize (Optional)
  POST http://localhost:8000/api/v1/audio/v2/summarize/{task_id}
  Body: {
    "summary_type": "detailed",
    "include_context": true,
    "async_mode": true
  }
  Response: {"task_id": "...", "status": "summarizing"}
  
  Step 5: Poll Again
  GET http://localhost:8000/api/v1/audio/v2/tasks/{task_id}/status
  Response: {"status": "summarized", "summary": "..."}
