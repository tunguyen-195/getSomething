║                         TROUBLESHOOTING                                    ║
╚════════════════════════════════════════════════════════════════════════════╝

Q: Script không chạy?
A: Right-click → "Run as Administrator"

Q: Redis không start?
A: Check Redis đã cài chưa: where redis-server

Q: Backend lỗi import?
A: Check virtual environment: venv\Scripts\activate

Q: Frontend không start?
A: cd frontend && npm install

Q: Port conflict?
A: netstat -ano | findstr "3000 8000"
   → Kill process: taskkill /F /PID <PID>

Q: Celery không chạy?
A: Check Redis: redis-cli ping
   → Should return: PONG
